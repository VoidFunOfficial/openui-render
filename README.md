# LearnGPT

LearnGPT 是基于 React 和 Pi 的学习助手，适配桌面和手机浏览器。每个学习项目有独立的对话历史。回答支持流式文字和可交互的卡片、表单与图表。[Open Intelligent UI](https://github.com/thesysdev/open-intelligent-ui)

## 项目和历史记录

点击对话页右上角的项目名，创建或切换学习项目。侧栏的「搜索本项目」可按标题、问题、回答和已发送的文本附件查找记录，点击摘录即可跳到原对话。旧版记录在升级后归入「默认项目」。

智能体在同一对话中沿用该对话的 Pi 历史，跨对话回顾时按需调用只读工具。两种项目工具均绑定发起本次对话的项目，检索范围为已完成、未归档的问答。

| 工具 | 用法 |
| --- | --- |
| `search_project_context` | 按关键词查找片段，省略关键词时返回最近记录。结果含对话标题、轮次标识和片段位置 |
| `read_project_context` | 按轮次标识和可选位置分段阅读原文 |
| `render2img` | 把 OpenUI 程序渲染成 PNG，供模型检查并展示给学习者，见下文 |

## 本地运行

使用 Node.js 24，在项目目录执行以下命令。

```sh
nvm use
npm ci
cp .env.example .env.local
```

两个预置 Agent 默认使用 `openai/gpt-5.4-mini`。将 `OPENAI_API_KEY` 写入 `.env.local`，或使用对应供应商的现有 Pi 登录凭据。模型凭据由服务端读取。

```sh
npm run dev
```

打开 [LearnGPT](http://127.0.0.1:3000)。服务绑定回环地址。切换端口可使用 `npm run dev -- --port 3100`。

## 渲染预览图（render2img）

`render2img` 让智能体把自己写的 OpenUI 程序渲染成 PNG。服务端用无头 Chrome 打开本应用的 `/render` 页面，按聊天中的样式渲染，等图片、字体和图表加载完再截图。图片和解析器发现的问题（未定义的引用、未知组件、被截断的程序、引号外被忽略的字符）一起返回给模型。支持看图的模型会检查图片，不支持的模型只收到问题列表。学习者在工具调用下方看到预览图，可以打开原图或下载。

- 智能体在输出复杂页面（Svg 图、图表、带状态的练习、约 25 行以上的程序）之前先预览一次，修正问题后再输出。学习者要海报、总结卡片等图片时，图片就是回答。
- 回答里随后显示了同一页交互视图时，预览图收在工具调用里；只有图片时，预览图直接显示。
- 宽度 320 到 1200 px，默认 480 px（手机宽度），可选浅色或深色主题，页面高于 6000 px 会截断。每个回答最多调用 3 次。开场请求和输出形式为 `markdown` 的智能体不提供此工具。
- 图片保存在 `.learnev/renders/<id>.png`，通过 `/api/renders/<id>` 访问，只接受本机请求。保存的 Pi 历史会去掉图片数据，后续轮次不会重复发送。

需要本机安装 Chrome、Chromium 或 Edge。服务端按以下顺序查找：`LEARNEV_CHROME`、`CHROME_PATH`、`PUPPETEER_EXECUTABLE_PATH`、系统默认安装位置、Playwright 缓存。服务器上没有浏览器时，可以运行 `npx playwright install chromium-headless-shell`。

| 环境变量 | 用途 |
| --- | --- |
| `LEARNEV_CHROME` | Chrome 或 Chromium 可执行文件路径 |
| `LEARNEV_CHROME_NO_SANDBOX=1` | 容器内无法使用 Chrome 沙箱时关闭沙箱。以 root 运行时自动关闭 |
| `LEARNEV_RENDER_ORIGIN` | 截图时访问的应用地址，默认使用当前请求的地址，例如 `http://127.0.0.1:3000` |

浏览器在首次渲染时启动，空闲 60 秒后退出。找不到浏览器时工具返回错误，智能体会继续正常回答。
## 配置 Agent

侧栏「设置」打开独立设置页。「智能体」中可以添加或编辑名称、系统提示词、服务、模型、推理强度、回答形式和工具。编辑时可以直接配置当前服务或添加新服务，保存服务后继续编辑智能体。保存后即可在输入框中选择它。每个智能体占用 `agent/` 下的一个子目录，目录名可以随名称生成，也可以自行填写。

「设置 → 模型服务」集中列出智能体使用的模型服务和 Pi 内置服务。点击已有服务可以编辑地址或更换凭据，密钥留空会沿用现有凭据。接入自定义端点时，点「添加模型服务」，填写唯一的服务标识、接口协议、Base URL、模型 ID 和 API Key。模型 ID 可以每行一个，无鉴权的本地服务可将密钥留空。服务使用 Pi 的 `models.json` 格式。设置中输入的密钥通过 Pi 写入私有的 `.learnev/provider-auth/<服务标识>.json`，项目模型清单只包含服务定义。已有 Pi 供应商继续沿用原有的登录凭据或环境变量。

也可以直接修改配置文件，在侧栏「智能体」里刷新。下一次发送会读取最新配置。

| 文件 | 用途 |
| --- | --- |
| `agent/<id>/agent.json` | 名称、供应商、模型、推理强度、工具、输出形式和开场建议 |
| `agent/<id>/system.md` | 该 Agent 的系统提示词 |
| `agent/models.json` | 可选的 Pi 自定义供应商与兼容模型 |

`output` 可选 `auto`、`openui` 或 `markdown`。`auto` 让模型按任务选择普通文字或交互界面。`tools` 接受上表中的工具名称，空数组表示关闭项目检索和预览图。所有智能体都自带 `end` 工具。预置的「学习搭子」和「学习导师」均可检索本项目历史和使用预览图，前者按任务选择回答形式，后者默认生成交互式学习内容。

如需接入自有的 OpenAI 兼容服务，可在 `agent/models.json` 中声明该服务。将示例地址和模型名换成实际值，在 `.env.local` 设置 `LOCAL_MODEL_KEY`，然后把目标 Agent 的 `provider` 和 `model` 改为对应名称。[Pi 模型配置](https://pi.dev/docs/latest/models-configuration)

```json
{
  "providers": {
    "local": {
      "baseUrl": "http://127.0.0.1:8000/v1",
      "api": "openai-completions",
      "apiKey": "$LOCAL_MODEL_KEY",
      "models": [{ "id": "my-model" }]
    }
  }
}
```

## 对话与数据

- 每次提问会并发请求同一个模型。开场请求关闭推理，用一句话或两三条要点点明主旨。主请求从一开始就使用输入框选定的推理强度，未指定时沿用智能体设置。界面先显示开场，再接上主请求的思考、工具和正文。用户选择关闭推理时，直接衔接正文或工具。停止生成会取消两路请求。
- 如果模型声明无法关闭推理，或开场请求失败或超时，界面直接显示主回答。主回答完成后单独调用 `end`。如果第 16 个主模型步骤仍未成功结束，会保留已生成内容并提示错误。
- 正文和交互组件随片段到达而显示。生成结束后可以展开各段「思考过程」回看。OpenAI 和 Anthropic 兼容接口使用 SSE 事件流。
- 回答中的 OpenUI 程序可以直接输出，也可以放在 ```` ```openui ```` 代码块中，代码块后的文字照常显示。模型在引号外写了中文键名、`.字段`、全角标点或弯引号时，界面会先修正再渲染。交互视图有问题时，下方会列出问题，并提供「源码」「复制」和「请助手修复」。
- 用输入框的 Agent 菜单切换角色。切换后会沿用当前对话的 Pi 历史。按 Enter 发送，Shift+Enter 换行。
- 点输入框旁的闪电按钮，拖动滑块调整当前对话主回答的思考强度。可选档位取决于模型，发送时随对话保存。点复位按钮可恢复智能体的默认强度。
- `⌘/Ctrl + I` 新建对话，`⌘/Ctrl + K` 搜索对话，`⌘/Ctrl + \` 折叠侧栏。已归档对话可在设置中恢复。
- Pi 上下文和聊天记录保存在 `.learnev/workspace.sqlite`，预览图保存在 `.learnev/renders/`。交互组件的绑定值和外观设置保存在当前浏览器。文本附件每条最多 4 个，每个最多 64 KB。
